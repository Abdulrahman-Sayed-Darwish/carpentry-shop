# متطلبات المشروع: موقع محل النجارة

## المستخدمون

- **العميل (Visitor):** أي شخص يزور الموقع، مش محتاج حساب.
- **الأدمن (النجار):** صاحب المحل، بيسجّل دخول بباسورد ويدير المحتوى.

## User Stories

### US-1: معرض الأعمال

كعميل، أريد أن أشاهد معرض أعمال المحل مقسّمًا حسب النوع (مطابخ، غرف نوم، أبواب...) لأقرر هل المحل مناسب لي.

**معايير القبول (Acceptance Criteria):**

- تظهر الأعمال في شبكة صور مع العنوان
- أقدر أفلتر حسب التصنيف
- الصفحة تشتغل كويس على الموبايل

### US-2: تفاصيل العمل

كعميل، أريد أن أفتح أي عمل وأشوف صوره كلها ووصفه لأفهم مستوى الجودة.

**معايير القبول:**

- صفحة لكل عمل فيها كل الصور والوصف والتصنيف
- لو العمل مش موجود تظهر رسالة "غير موجود"

### US-3: طلب عرض سعر

كعميل، أريد أن أرسل طلب عرض سعر (الاسم، التليفون، نوع الشغل، التفاصيل) لأحصل على تقدير التكلفة.

**معايير القبول:**

- كل الحقول المطلوبة بتتفحص قبل الإرسال
- رقم التليفون لازم يكون رقم مصري صحيح
- تظهر رسالة نجاح بعد الإرسال ورسالة واضحة لو حصل خطأ

### US-4: تسجيل دخول الأدمن

كأدمن، أريد أن أسجّل دخول بباسورد لأدخل على لوحة التحكم بشكل آمن.

**معايير القبول:**

- صفحات ومسارات الأدمن محمية ومش بتفتح بدون تسجيل دخول
- لو الباسورد غلط تظهر رسالة خطأ
- تسجيل الخروج متاح

### US-5: إدارة المعرض

كأدمن، أريد أن أضيف وأعدّل وأمسح أعمال من المعرض لأحدّث الموقع بنفسي.

**معايير القبول:**

- فورم لإضافة عمل جديد مع رفع صور
- تعديل وحذف أي عمل (مع رسالة تأكيد قبل الحذف)
- التغييرات تظهر فورًا في المعرض

### US-6: متابعة الطلبات

كأدمن، أريد أن أشوف طلبات عروض الأسعار وأغيّر حالة كل طلب (جديد / تم التواصل / قيد التنفيذ / تم التسليم) لأنظّم شغلي.

**معايير القبول:**

- قائمة بكل الطلبات الأحدث أولًا
- أقدر أغيّر حالة أي طلب
- أقدر أفلتر الطلبات حسب الحالة
